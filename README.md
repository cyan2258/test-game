# 2048 数字合成小游戏

一个使用原生 HTML、CSS 和 JavaScript 编写的轻量级 2048 小游戏。项目没有第三方依赖，不需要构建或安装环境，打开网页即可游玩。

## 功能

- 经典 4 × 4 2048 合并规则
- 方向键与 `W` / `A` / `S` / `D` 操作
- 移动端触摸滑动操作
- 自动生成 2 或 4 方块
- 分数与最高分记录（保存于浏览器 `localStorage`）
- 合成 2048 后提示胜利，同时可以继续挑战
- 无法继续移动时提示游戏结束
- 响应式布局，适配桌面和手机屏幕

## 运行方式

### 方式一：直接打开

双击项目根目录的 `index.html`，使用现代浏览器打开即可。

### 方式二：启动本地静态服务器

如果希望通过本地服务器运行，可以在项目目录执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作说明

| 操作 | 作用 |
| --- | --- |
| `↑` / `W` | 向上移动 |
| `↓` / `S` | 向下移动 |
| `←` / `A` | 向左移动 |
| `→` / `D` | 向右移动 |
| 手机滑动 | 按滑动方向移动方块 |
| 新游戏 | 重置当前棋盘 |

## 游戏规则

每次操作会让所有方块向指定方向移动。两个相同数字相撞时会合并成它们的和，并获得相应分数。例如两个 `8` 会合并为 `16`。每次有效移动后，棋盘会在空白位置随机生成一个 `2` 或 `4`。

当棋盘上出现 `2048` 时即达成目标；如果棋盘填满且不存在可以合并的相邻方块，游戏结束。

## 技术说明

- 使用 CSS Grid 绘制棋盘。
- 游戏状态保存在 JavaScript 内存中，最高分使用浏览器本地存储保存。
- 合并算法先压缩非空方块，再从移动方向开始遍历合并，最后补齐空位。
- 采用原生事件监听实现键盘控制、按钮控制和触摸手势。
